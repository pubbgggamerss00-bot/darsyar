# درسیار من 🎓 (کمک درسی متوسطه اول)

اپلیکیشن کمک‌درسی فارسی برای دانش‌آموزان **پایه هفتم، هشتم و نهم** — هم به‌صورت وب‌اپ (Next.js) و هم به‌صورت **اپ اندروید آفلاین (APK)**.

## امکانات

- 📚 **انتخاب پایه تحصیلی** (هفتم / هشتم / نهم)
- 📖 نمایش **کتاب‌های درسی** هر پایه (ریاضی، علوم تجربی، فارسی، مطالعات اجتماعی، عربی، انگلیسی، پیام‌های آسمان، کار و فناوری)
- ✅ **جواب سوالات** به‌صورت فصل‌به‌فصل و مرحله‌به‌مرحله
- 💡 **نکات مهم** و فرمول‌های کلیدی هر فصل
- 📝 **سوالات امتحانی** با پاسخ تشریحی (قابل باز و بسته شدن)
- 🤖 **دستیار هوشمند (هوش مصنوعی)**: پاسخ به سوالات درسی متناسب با پایه‌های ۷ تا ۹ — برای وقتی که جواب سوالت را در بخش کمک درسی پیدا نکردی

## ساختار پروژه

```
├── src/app/                 # اپ وب Next.js 16 (App Router)
│   ├── page.tsx             # رابط کاربری تک‌صفحه‌ای (خانه/پایه/کتاب/چت)
│   └── api/                 # APIها: grades، books، chat (هوش مصنوعی)
├── src/components/darsyar/  # کامپوننت‌های UI
├── src/data/                # محتوای درسی ۲۴ کتاب (۷۲ فصل، ۴۳۲ محتوا)
├── prisma/                  # اسکیمای دیتابیس SQLite + اسکریپت Seed
├── apk/                     # پروژه اپ اندروید (WebView آفلاین)
│   ├── assets/www/          # نسخه آفلاین کامل محتوا (بدون نیاز به اینترنت)
│   ├── build.sh             # ساخت APK بدون Android Studio
│   └── darsyar.apk          # خروجی نهایی امضاشده
└── scripts/                 # اسکریپت‌های کمکی (آیکون، صفحه آفلاین)
```

## اجرای نسخه وب

```bash
bun install
bun run db:push        # ساخت دیتابیس SQLite
bun prisma/seed.ts     # بارگذاری محتوای درسی
bun run dev            # اجرا روی http://localhost:3000
```

## ساخت APK اندروید

APK آماده در مسیر `apk/darsyar.apk` موجود است. برای ساخت مجدد:

```bash
bash apk/build.sh
```

این اسکریپت به‌صورت خودکار ابزارهای اندروید (build-tools و platform-34) را دانلود و APK را کامپایل، هم‌تراز و امضا می‌کند — بدون نیاز به Android Studio یا Gradle.

### ویژگی‌های نسخه اندروید

- 🔌 **آفلاین**: تمام محتوای درسی (جواب سوالات، نکات، سوالات امتحانی) داخل APK است و بدون اینترنت کار می‌کند
- 🤖 **دستیار هوشمند**: با زدن دکمه چرخ‌دنده در صفحه چت، آدرس سرور نسخه وب را وارد کنید تا دستیار هوشمند فعال شود (سرور باید `/api/chat` را ارائه دهد)

## فناوری‌ها

Next.js 16 · TypeScript · Tailwind CSS 4 · shadcn/ui · Prisma (SQLite) · z-ai-web-dev-sdk (هوش مصنوعی) · WebView اندروید
