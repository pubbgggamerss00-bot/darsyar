# درس‌یار 📚

اپلیکیشن اندروید «درس‌یار» — همراه آموزشی دوره اول متوسطه (پایه هفتم تا نهم)، ساخته‌شده از طرح‌های استیچ (Stitch) به‌صورت اپلیکیشن WebView با رابط کاربری کاملاً فارسی و راست‌به‌چپ.

|---|---|---|
| Darsyar-v1.0.apk | ۶٫۱ MB | [Releases](../../releases) — فایل `Darsyar-v1.0.apk` |

### نصب
1. فایل APK را روی گوشی اندروید (۷٫۰ به بالا) دانلود کنید.
2. هنگام نصب، اجازه «نصب از منابع ناشناس» را بدهید.
3. اپلیکیشن کاملاً آفلاین کار می‌کند — نیازی به اینترنت نیست.

## ✨ امکانات

- **۱۸ صفحه طراحی‌شده** در ۴ بخش: شروع، هوش مصنوعی دانا، درس‌ها و کتاب‌ها، کتاب‌خوان تعاملی
- **فهرست اصلی** با دسته‌بندی موضوعی و دسترسی سریع به هر صفحه
- **ناوبری شناور** در همه صفحات (خانه / قبلی / بعدی) + جابه‌جایی با کشیدن انگشت
- **کاملاً آفلاین**: فونت وزیرمتن، آیکون‌های Material Symbols و همه تصاویر داخل خود APK
- طراحی فارسی RTL با سیستم رنگ ایندیگو/فیروزه‌ای و تجربه گیمیفایکیشن

```
│   └── assets/       # فونت، تصاویر، Tailwind

```

## 🔧 بازساخت APK

پیش‌نیازها: JDK (جاوا)، Android build-tools 34، platform-34 (android.jar) و ECJ.

```bash
# مسیر ابزارها را در اسکریپت تنظیم کنید سپس:
bash android/build_apk.sh
```

مراحل اسکریپت: `aapt2 compile/link` → کامپایل جاوا (ECJ) → `d8` → بسته‌بندی → `zipalign` → امضا با `apksigner`.
